# Progressbar

Tag: `<x-nb-mobile::progressbar>`

Linear progress indicator (0 to 100).

## Usage

```blade
<x-nb-mobile::progressbar :value="35" />
<x-nb-mobile::progressbar :value="$progress" color="emerald-500" />
```

## Props

| Prop | Default | Description |
|---|---|---|
| `value` | `0` | 0 to 100 |
| `color` | theme primary | |
